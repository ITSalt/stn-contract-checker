### Трения, от самого важного

1. **Браузерная проверка падает на чистом Debian или Ubuntu.** `install chromium` не ставит системные библиотеки и ничего о них не говорит, `e2e:shots` выдаёт `2 failed` с ошибкой `libglib-2.0.so.0`. В «Частые проблемы» это не описано. Предлагаю шаг 1 заменить так: «`npx playwright install --with-deps chromium` (на Linux нужен root или sudo; ставит около 95 пакетов apt, примерно 1–2 мин)». В «Частые проблемы» добавить: «**`error while loading shared libraries: libglib-2.0.so.0`** → `npx playwright install-deps chromium`».
2. **Не сказано, что нужны git и curl.** В «Требованиях» есть Node и интернет, но шаг 1 использует `git`, шаг 6 использует `curl`, а в `node:22-slim` нет ни того, ни другого. Добавить: «git и curl (в slim-образах: `apt-get update && apt-get install -y git curl ca-certificates`)».
3. **Ожидание `0 failed` нельзя проверить буквально.** Vitest 5 при полном успехе не печатает слово `failed`. Заменить на: «exit 0, итоговая строка `Tests 295 passed (295)`; если есть упавшие, в строке будет `N failed`».
4. **Шаг 5 не объясняет, как совмещается с остальными.** Сервер блокирует терминал, а шаг 6 и приёмка требуют, чтобы он работал. Нужно написать «запустите в фоне (`nohup … &`) или в отдельном терминале и подождите `ready`». Также стоит указать, что `e2e:shots` поднимает **свой** сервер на 5291 и dev-сервер для него не нужен (сейчас это есть только в README).
5. **«Ответы должны совпадать с таблицей README» — неясно, насколько строго.** Значения совпали, но текст ответов в приложении короче, чем в README. В Q1 вместо «проект на 10.05.2026» написано «есть несогласованные изменения: 1» (дата 10.05.2026 видна ниже, в «Сведениях для проверки»). В Q2 нет фразы про аванс 252 000 ₽. Стоит явно написать: «совпадать должны значения (дата, сумма, источник, список договоров), а не формулировка».
6. **Приёмку руками без браузера агенту не пройти.** «Откройте приложение, нажмите…» на машине без GUI невыполнимо до браузерной проверки. Предлагаю переставить разделы: «приёмка = снимки `02-uploaded-table` и `05`–`08` из `e2e:shots`, сверить с таблицей».
7. Мелочь: в шаге 1 URL с `.git`, в задании без — работает и так. Предупреждение npm о новой мажорной версии безвредно, его можно упомянуть как ожидаемое.
