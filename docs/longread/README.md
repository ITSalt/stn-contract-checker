# Иллюстрированный дневник разработки

[Читать на GitHub Pages](https://itsalt.github.io/stn-contract-checker/).

Полный текст лонгрида «Лог выполнение тестового задания для Стереос Групп» и все 61 изображение
из [исходной Page](https://chatgpt.com/space/page_0e94e60c71008191b2775f6ed68638c0), экспорт 30 октября 2026 года.
Текст и порядок иллюстраций сохранены. Для навигации добавлены семь разделов.

## Открыть без интернета

Скачайте репозиторий кнопкой **Code → Download ZIP**, распакуйте и откройте
`docs/longread/index.html` двойным щелчком. Переносить нужно всю папку `longread`, включая `assets/`.
Можно также скачать только ветку `gh-pages`: в её ZIP файл `index.html` лежит прямо в корне.

Сервер, Node.js, установка пакетов и сборка не нужны. Стили и скрипт встроены в HTML,
все картинки находятся рядом в `assets/`. CDN, внешних шрифтов, аналитики и сетевых запросов нет.
Внешние ссылки на GitHub и исходную Page открываются при наличии интернета.

## Просмотр картинок

- Нажатие на картинку открывает полноэкранный просмотрщик с исходным файлом.
- `+` / `−`, колесо мыши или жест двумя пальцами меняют масштаб до 800%.
- Перетаскивание перемещает увеличенное изображение. Двойной клик переключает увеличение и вписывание.
- **1:1** (клавиша `1`) — исходный размер; **Вписать** (клавиша `0`) — целиком в окне.
- `←` / `→` переключают изображения, `Esc` закрывает просмотрщик.
- **Оригинал** открывает исходный файл в отдельной вкладке, **Скачать** сохраняет его.

Без JavaScript текст остаётся доступен, а нажатие на картинку открывает сам файл
для просмотра встроенными средствами браузера.

## Файлы

- `index.html` — готовая автономная страница с CSS и JavaScript внутри.
- `assets/01.png` … `assets/61.png` — оригиналы без изменения размеров и повторного сжатия.
- `source.md` — текст и изображения в порядке исходной Page, со ссылками на локальные файлы.
- `assets-manifest.json` — размеры, объём и SHA-256 каждого изображения.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## GitHub Pages

Источник публикации — ветка `gh-pages`, каталог `/`. Она содержит только эту страницу и её файлы.
Приложение в корне `main` и его сборка остаются отдельными.

После изменения `docs/longread/` в `main` обновить опубликованную копию можно из корня репозитория:

```bash
git subtree split --prefix docs/longread -b longread-publish
git push origin longread-publish:gh-pages
git branch -d longread-publish
```

В настройках **Settings → Pages** должен быть выбран источник **Deploy from a branch**,
ветка `gh-pages`, папка `/ (root)`.
